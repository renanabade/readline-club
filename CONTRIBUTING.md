# Contribuições

O código do readline club é aberto **por transparência**: para que membros e qualquer pessoa interessada possam ver como a plataforma funciona e como os dados são tratados. O desenvolvimento é feito pela organização do clube.

- **Pull requests externos não são aceitos** e são fechados automaticamente.
- **Pedidos de funcionalidade** podem ser levados ao clube pelos grupos de membros.
- **Bugs** podem ser relatados em uma issue, pelo template. Não inclua dados pessoais.
- **Vulnerabilidades de segurança** nunca devem ser relatadas em issues: siga o [SECURITY.md](SECURITY.md).

O processo interno de desenvolvimento (escopo, commits, testes e revisão) está documentado em [`docs/`](docs/README.md).
