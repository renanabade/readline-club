# Segurança

Se você encontrou uma vulnerabilidade, **não abra uma issue pública**. Use o recurso [Report a vulnerability](../../security/advisories/new) na aba **Security** deste repositório, que cria um relato privado para os mantenedores.

Inclua, se possível:

- o que é afetado (rota, componente ou configuração);
- os passos para reproduzir;
- o impacto esperado.

Responderemos assim que possível e combinaremos a divulgação depois da correção. Testes devem ser feitos apenas em uma instalação local (`npm run dev`), nunca em https://readline.club ou em contas de outras pessoas.
