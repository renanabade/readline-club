# Documentação interna

Como o readline club é desenvolvido e entregue. O repositório é público por transparência: qualquer pessoa pode ler o código e este processo, mas o desenvolvimento é feito pela organização do clube (veja [CONTRIBUTING.md](../CONTRIBUTING.md)).

| Documento                                           | Quando ler                                                                          |
| --------------------------------------------------- | ----------------------------------------------------------------------------------- |
| [Entrega](entrega.md)                               | Antes de começar qualquer mudança: escopo, branch, commit, PR, deploy.              |
| [Arquitetura e padrões](arquitetura.md)             | Ao escrever código: onde cada coisa fica e como deve ser escrita.                   |
| [Testes](testes.md)                                 | Ao decidir o que testar e como.                                                     |
| [Segurança e privacidade](seguranca-privacidade.md) | Em toda mudança que toca dados, rotas, e-mails ou configuração.                     |
| [Operação](operacao.md)                             | Para rodar localmente, criar a conta administrativa, configurar e-mails e publicar. |

O [README](../README.md) explica o produto e o tratamento de dados para o público. Estes documentos são para quem mantém a plataforma. Quando um deles mudar, atualize-o no mesmo PR da mudança que motivou a alteração.
